## Order Flow (Master → Touch → Gallery Cloud → Management Cloud)

### Step 1: Master → Touch (Photo Export)
```
Master                          Touch Kiosk
   │                                  │
   │  1. Photographer shoots photos    │
   │  2. Creates album               │
   │  3. Exports to Touch            │
   │────────────────────────────────►│
   │     (watermarked previews)       │
   │                                  │
```

### Step 2: Touch → Master (Customer Selection)
```
Touch Kiosk                     Master
   │                                  │
   │  1. Customer views photos        │
   │  2. Selects favorites           │
   │  3. Creates order               │
   │────────────────────────────────►│
   │     (selected photo IDs)         │
   │                                  │
   │  4. Order saved locally          │
   │  5. status = 'pending'           │
```

### Step 3: Master → Customer Gallery Cloud (Auto-Upload on Validation)
```
Master                          Gallery Cloud                    Customer
   │                                  │                              │
   │  1. Order validated (paid)      │                              │
   │  2. Photos watermarked          │                              │
   │  3. Auto-upload to Gallery ────►│                              │
   │  4. Order synced                │                              │
   │  5. Access PIN generated        │                              │
   │  6. Email sent ─────────────────────────────────────────────►│
   │                                  │                              │
   │                                  │  7. Customer views gallery    │
   │                                  │  8. Purchases photos         │
```

### Step 4: Master → Management Cloud (Auto-Sync Sales Data)
```
Master                          Management Cloud
   │                                  │
   │  1. Order completed              │
   │  2. Daily audit generated       │
   │────────────────────────────────►│
   │     (sales_revenue, sold_photos, │
   │      imported_photos, etc.)       │
   │                                  │
   │  3. Analytics aggregated         │
   │  4. Dashboard updated            │
```

## Cloud Sync Architecture

### Gallery Cloud Sync
| Endpoint | Purpose | Trigger |
|----------|---------|---------|
| `/api/cloud/sync/order` | Sync validated orders | Order status = 'paid' |
| `/api/cloud/sync/album` | Sync album metadata | Album created/updated |
| `/api/cloud/upload-photo` | Upload watermarked photos | Order validated |
| `/api/cloud/sync/operations` | Batch operations | Periodic sync |

### Management Cloud Sync
| Endpoint | Purpose | Trigger |
|----------|---------|---------|
| `/api/analytics/daily-audit` | Photographer performance | Daily (midnight) |
| `/api/analytics/resort-ingest` | Resort BI data | Periodic sync |
| `/api/cloud/sync/settings` | Global config push | On demand |
| `/api/cloud/sync/operations` | Bi-directional ops | Periodic sync |

### Sync Configuration (Auto-generated per installation)
```bash
# .env generated by installer
CLOUD_API_URL=https://management.clicketflash.com
CLOUD_GALLERY_URL=https://gallery.clicketflash.com
CLOUD_EMAIL=admin@{slug}.clicketflash.com
DESK_ID={slug}
SYNC_ENABLED=true
SYNC_INTERVAL_MS=60000
```

## 1-Click Installation Command

### Current (Working)
```bash
cd apps/master && npx tsx scripts/install-cli.ts \
  --location "Hotel Name" \
  --email admin@hotel.com \
  --password SecurePass123! \
  --cf-token cfut_... \
  --cf-account 0e00f... \
  --cf-zone ee196... \
  --cf-domain clicketflash.com
```
