# 1-Click Installation Plan: Destination Name Only

## Goal
**"Put destination name → Get working system"** - Minimal input, maximum automation.

---

## Streamlined Installation Flow

### Before (Current)
```
1. Edit bootstrap.json manually
2. Fill in: locationName, adminEmail, adminPassword, cloudflareConfig, hubUrl
3. Copy to pb_data/
4. Hope it works
5. Debug if it doesn't
```

### After (Target)
```
1. Edit ONE file: destinations.csv (or just destination name)
2. Run: npm run bootstrap -- --destination "Paradise Resort"
3. System auto-generates everything
4. Done
```

---

## Implementation: `destinations.csv` Approach

### File: `apps/master/destinations.csv`
```csv
locationName,adminEmail,adminPassword,hubUrl,timezone
Paradise Resort,admin@paradise.com,${ADMIN_PASS},https://hub.clickflash.photo,Africa/Tunis
Ocean Hotel,admin@ocean.com,${ADMIN_PASS},https://hub.clickflash.photo,Europe/Paris
```

### Bootstrap Generator Script
```bash
# Usage: npm run bootstrap -- --destination "Paradise Resort"
# Or interactive: npm run bootstrap
```

## Auto-Generated Configuration

System auto-generates `bootstrap.json` with:

| Field | Source | Example |
|-------|--------|---------|
| locationName | CSV or CLI arg | "Paradise Resort" |
| adminEmail | Default + domain | admin@paradise.clickflash.photo |
| adminPassword | ENV: `ADMIN_PASSWORD` | (from environment) |
| hubUrl | Fixed | https://hub.clickflash.photo |
| cloudflareConfig | Auto-detected | Uses existing CF token if available |
| deskId | Auto-generated | `PR-XXXXXXXX` (2-letter prefix from name) |

### Step 2: Simplify BootstrapService
- Auto-detect bootstrap.json location (Windows compatible)
- Support env var placeholders: `${VAR_NAME}`
- Validate with Zod schema
- Never log passwords

### Step 3: Create destinations.csv Template
- Pre-fill demo destinations
- Document env var usage

### Step 4: Add CLI Bootstrap Command
- Add to `package.json`: `"bootstrap": "ts-node scripts/generate-bootstrap.ts"`

### Step 5: Add Circuit Breaker to CloudSync
- Prevent sync storms when Hub unreachable
- 10 failures → pause 5 min → retry
