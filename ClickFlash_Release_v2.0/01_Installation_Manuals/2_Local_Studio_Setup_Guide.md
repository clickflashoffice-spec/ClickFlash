# Local Studio Setup Guide (Master & Touch)

## Prerequisites
- Windows 10/11 or macOS 12+
- Node.js 20+ (if running from source) or the All-in-One Installer (`apps/installer`)

## Installation Steps
1. Run the All-in-One Installer (`ClickFlash-Installer-v2.0.exe`).
2. Select your desired components:
   - **Master Portal**: Installs local SQLite server, WebSocket LAN broker, and POS dashboard.
   - **Touch Kiosk**: Installs customer touch interface and mDNS Bonjour discovery client.
3. Import your offline Ed25519 license key (`license.key`) generated by your studio administrator.
4. Launch Master Portal (`http://localhost:8090`).
5. Launch Touch Kiosk (`http://localhost:8091`). Touch Kiosk will automatically discover the Master node via mDNS (`clickflash-touch`).
