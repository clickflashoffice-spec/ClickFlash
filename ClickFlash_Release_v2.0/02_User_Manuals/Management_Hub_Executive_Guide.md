# Management Hub Executive Guide

## Executive Dashboard
Access the cloud Management Hub (`apps/management`) to oversee your entire studio fleet across multiple resorts.

## Key Capabilities
- **Fleet Monitor**: Live status ping of all Master nodes.
- **Cmd+K Command Palette**: Rapid navigation across stations, sales, and analytics.
- **PixelFounder AI Chatbot**: Local/D1 data querying for natural language financial summaries.
