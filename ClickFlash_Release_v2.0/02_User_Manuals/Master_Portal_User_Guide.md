# Master Portal User Guide

## Dashboard Overview
The Master Portal (`apps/master`) is the operational heart of your photography studio.

## Key Features
1. **WASM Photo Editor**: Select any photo and click **Auto Edit** for local Canvas/WASM auto-exposure and cropping.
2. **Thermal Monitor**: Keep an eye on CPU and hardware thermal loads during high-volume ingest.
3. **Print Layout**: Generate customer receipts and print sheets with pixel-perfect layouts.
4. **LAN Sync**: Automatically connects with local Touch Kiosks over WebSocket (`ws://localhost:8090`).
