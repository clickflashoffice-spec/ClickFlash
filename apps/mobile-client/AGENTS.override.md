# Mobile Client App Override Rules

> **Target**: `apps/mobile-client` (Expo React Native)

## Domain Context
Consumer app for gallery viewing and interactions.

## Specific Constraints
- **Framework**: Expo React Native.
- **UX**: Must adhere to strict mobile-first design patterns matching the Gallery Web Portal experience but optimized for native.

## AI Instructions
Treat as a high-touch UI surface. Adhere strictly to StyleSeed UI patterns and provide fluid gesture-based interactions.
