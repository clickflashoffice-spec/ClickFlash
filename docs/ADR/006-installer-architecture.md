# ADR 006: Unified Ecosystem Installer

## Status

**Accepted**

## Context

Deploying ClickFlash to hotel, venue, or studio computers requires installing two desktop applications (Master and Touch) plus Windows-specific configurations:

- Firewall rules for local HTTP/WebSocket ports (8090, 8091) and mDNS (UDP 5353).
- High-performance power plan to prevent sleep during events.
- Auto-start registry entries so both apps resume after reboot.

Previously, these steps were manual or used fragile `.bat` scripts. We needed a single, robust installation experience.

## Decision

We will use a **Unified Installer Architecture** based on **Inno Setup** as the outer wrapper, integrating the NSIS installers generated by `electron-builder`.

### Architecture Flow

1. **Frontend builds**: `apps/master` and `apps/touch` use `electron-builder` to produce silent NSIS installers (`.exe`).
2. **Wrapper**: A single Inno Setup script (`ClickFlash_Ecosystem_Setup.iss`) bundles:
   - `ClickFlash-Master-OS-Setup.exe`
   - `ClickFlash-Touch-Kiosk-Setup.exe`
3. **Bootstrapping**: The Master NSIS installer executes `installer.nsh`, which runs `windows-kiosk-setup.ps1` after unpacking.
4. **System configuration**: The PowerShell script:
   - Configures Windows Firewall for mDNS and HTTP/WebSocket ports.
   - Sets the active power plan to High Performance.
   - Writes auto-start registry keys for both applications.

## Consequences

### Positive

- **Zero-touch deployment**: Venue IT staff or photographers run a single executable.
- **Resilience**: Apps automatically recover and boot into kiosk mode after power failures or reboots.
- **Maintainability**: `electron-builder` handles Electron packaging; custom scripts handle only Windows-specific ecosystem needs.
- **Professional presentation**: Branded installer with progress UI and error reporting.

### Negative

- **Windows-only**: macOS and Linux deployments require separate packaging decisions.
- **Build time**: Local installer testing requires a Windows environment and both Electron builds.
- **Privilege requirements**: Firewall and power-plan changes require administrator elevation.

### Neutral

- The installer is versioned and released alongside the desktop apps; the Auto-Loop can produce it automatically.
