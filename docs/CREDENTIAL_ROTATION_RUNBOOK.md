## 6. Stripe Dashboard Actions

### 6.1 Rotate API Keys

1. Go to [Stripe Dashboard → API Keys](https://dashboard.stripe.com/apikeys)
2. **Roll the secret key** — this immediately invalidates the old `sk_live_...` key
3. Copy the new secret key for use in the `wrangler secret put` commands above
4. If a test-mode key was also exposed, roll `sk_test_...` as well

### 6.2 Register Webhook Endpoints

Register the following webhook endpoints for each worker:

**Gallery Worker:**
- URL: `https://gallery-backend.<your-subdomain>.workers.dev/api/stripe/webhook`
- Events:
  - `checkout.session.completed`
  - `checkout.session.async_payment_succeeded`
  - `checkout.session.async_payment_failed`
  - `checkout.session.expired`
- Copy the `whsec_...` signing secret → use in `STRIPE_WEBHOOK_SECRET`

**MoneyTrash Worker:**
- URL: `https://moneytrash-api.<your-subdomain>.workers.dev/api/stripe/webhook`
- Events:
  - `checkout.session.completed`
  - `checkout.session.async_payment_succeeded`
  - `checkout.session.async_payment_failed`
  - `checkout.session.expired`
- Copy the `whsec_...` signing secret → use in `STRIPE_WEBHOOK_SECRET`

### 6.3 Verify Legacy `MT-TEST-01` Office

Check if the old MoneyTrash schema ever provisioned a test office:
```sql
-- Run against moneytrash-db
SELECT * FROM offices WHERE office_id = 'MT-TEST-01';
```
If found, delete or rotate that office's API key.

### Revocation Steps

1. Go to [Google Cloud Console → API Credentials](https://console.cloud.google.com/apis/credentials)
2. Find the key matching the value above
3. Click **Delete** or **Regenerate** (if still needed)
4. If the key powered any active services, create a new **restricted** key:
   - Restrict by HTTP referrer to your production domains only
   - Restrict by API to only the APIs you actually use
5. The current codebase does NOT use Google API keys (all AI features were migrated to local PixelFounder services)

> [!IMPORTANT]
> If no Google APIs are actively used, simply **delete** the key entirely.

## 8. Ed25519 License-Signing Key Rotation

### Generate New Keypair

```powershell
# Run the credential generation script
pwsh scripts/generate-credentials.ps1 -OutputDir C:\Users\alamo\Documents\clickflash-keys
```

### Embed Public Key

Update the public key in the licensing verification code:

1. [`packages/licensing/src/ed25519.ts`](file:///c:/Users/alamo/Desktop/ClickFlash/packages/licensing/src/ed25519.ts) — If a default public key is embedded, replace it
2. [`apps/license-generator/`](file:///c:/Users/alamo/Desktop/ClickFlash/apps/license-generator/) — Update the default public key reference
3. [`apps/installer/`](file:///c:/Users/alamo/Desktop/ClickFlash/apps/installer/) — The payload trust table is intentionally empty and separate from the license key

### Private Key Custody

- Move the private key PEM to an **offline USB drive**
- Label the drive: "ClickFlash License Signing Key — [date]"
- Store in a physically secure location
- The private key must NEVER be committed to Git, stored on a networked drive, or included in any ASAR/build artifact

### Legacy License Migration

Licenses signed with the old (compromised) key will no longer verify. Options:
1. **Re-sign** all active licenses with the new key
2. **Grace period**: Accept both old and new public keys for 30 days, then remove the old key

## 10. Collaborator Reclone Requirements

### Notification Template

```
Subject: [ClickFlash] MANDATORY: Reclone required after credential rotation

The ClickFlash repository has undergone a coordinated Git history rewrite
to purge leaked credentials from all historical commits.

REQUIRED ACTIONS:
1. Delete your local clone
2. Fresh clone: git clone <repo-url>
3. Reconfigure any local environment files
4. Update any saved branch references

ALL commit SHAs have changed. Do NOT force-push old branches.
Do NOT attempt to merge old branches into the new history.

If you have uncommitted work, export it as a patch file BEFORE deleting
your clone:
  git diff > my-uncommitted-work.patch

Then apply it to the new clone:
  git apply my-uncommitted-work.patch
```
