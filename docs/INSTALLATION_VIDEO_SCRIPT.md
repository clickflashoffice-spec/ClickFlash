# ClickFlash Installation Video Script

> **Duration:** 5 minutes
> **Target:** New customers installing ClickFlash Studio
> **Format:** Screen recording with voiceover

---

## 🎬 SCENE 1: INTRO (30 seconds)

**Visual:** ClickFlash logo animation, then fade to desktop

**Voiceover:**
"Welcome to ClickFlash Studio — the complete photo studio management system. In this video, I'll show you how to install ClickFlash on your Windows PC in under 5 minutes."

**On-screen text:**
- ClickFlash Studio v4.2.0
- Installation Guide
- www.clickflash.com

---

## 🎬 SCENE 2: DOWNLOAD (45 seconds)

**Visual:** Browser showing ClickFlash website

**Voiceover:**
"First, download the ClickFlash installer from your account dashboard. You'll receive a download link after purchasing your license. The file is about 94 megabytes and downloads in seconds."

**Screen actions:**
1. Open browser
2. Navigate to clickflash.com/download
3. Click "Download for Windows"
4. Show download progress

**On-screen text:**
- File: ClickFlash-Studio-Setup-5.0.0-x64.exe
- Size: 94 MB
- Time: ~10 seconds

---

## 🎬 SCENE 3: INSTALLATION (2 minutes)

**Visual:** Windows desktop with installer running

**Voiceover:**
"Double-click the installer to begin. Windows may show a SmartScreen warning since we're a new publisher. Click 'More info' then 'Run anyway' to continue. This warning will disappear once we complete our code signing certificate."

**Screen actions:**
1. Double-click EXE
2. Show SmartScreen warning
3. Click "More info" → "Run anyway"
4. Show installer welcome screen
5. Click "Next" through wizard
6. Show installation progress
7. Show completion screen

**On-screen text:**
- ⚠️ SmartScreen: Click "More info" → "Run anyway"
- Installation time: 2-3 minutes
- Requires: Windows 10/11, 4GB RAM, 500MB disk

---

## 🎬 SCENE 4: FIRST LAUNCH (1 minute)

**Visual:** ClickFlash Master app launching

**Voiceover:**
"ClickFlash automatically starts the backend server and opens your default browser. You'll see the splash screen while everything initializes. This takes about 30 seconds on first run."

**Screen actions:**
1. Click "Launch ClickFlash"
2. Show splash screen: "Starting ClickFlash Studio..."
3. Show backend initialization
4. Browser opens to localhost:8090
5. Show login screen

**On-screen text:**
- Backend auto-starts ✅
- No manual configuration needed
- Default login: admin / admin

---

## 🎬 SCENE 5: ACTIVATE LICENSE (45 seconds)

**Visual:** License activation screen

**Voiceover:**
"Enter your license key to activate all features. You received this key in your purchase email. The key looks like this: CF-LIVE followed by 16 characters. Click activate and you're ready to go."

**Screen actions:**
1. Click "Activate License"
2. Enter license key: CF-LIVE-XXXX-XXXX-XXXX-XXXX
3. Click "Activate"
4. Show success message

**On-screen text:**
- License key format: CF-LIVE-XXXX-XXXX-XXXX-XXXX
- Need a key? Visit clickflash.com/pricing

---

## 🎬 SCENE 6: CONNECT TOUCH KIOSK (30 seconds)

**Visual:** Master app settings → Kiosk Pairing

**Voiceover:**
"To connect a customer kiosk, go to Settings, then Kiosk Pairing. Generate a QR code and scan it with the Touch app. The kiosk automatically connects with zero configuration."

**Screen actions:**
1. Click Settings
2. Click Kiosk Pairing
3. Click Generate QR
4. Show QR code on screen

**On-screen text:**
- Connect unlimited kiosks
- Zero configuration pairing
- Works over Ethernet or WiFi

---

## 🎬 SCENE 7: OUTRO (30 seconds)

**Visual:** ClickFlash dashboard with sample data

**Voiceover:**
"That's it! ClickFlash Studio is now running. You can manage albums, orders, customers, and connect kiosks — all from one dashboard. For support, visit our documentation or contact our team. Thanks for choosing ClickFlash!"

**On-screen text:**
- ✅ Installation complete
- 📚 docs.clickflash.com
- 📧 support@clickflash.com
- 🌐 clickflash.com

---

## 🎥 PRODUCTION NOTES

### Recording Setup
- **Software:** OBS Studio or Camtasia
- **Resolution:** 1920x1080 (1080p)
- **Frame rate:** 30fps
- **Audio:** Clear voiceover, no background music

### Editing
- **Transitions:** Simple fade between scenes
- **Zoom:** Highlight important clicks
- **Text overlays:** Key information only
- **Duration target:** 5 minutes max

### Distribution
- **YouTube:** Primary hosting
- **Website:** Embedded on clickflash.com/install
- **Documentation:** Linked in README.md
