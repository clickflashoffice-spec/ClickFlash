# ClickFlash Master App — 360-Degree Action Plan (PLOA)

This document outlines the comprehensive audit and improvement plan for the **ClickFlash Master App** from first principles. It covers every screen, page, feature, and system layer, balancing business strategy (CEO), software architecture (Architect), and implementation details (Developer).

---

## 1. Executive Vision & Objectives (CEO Perspective)

As CEO, the priority is to maximize conversion rates, streamline local operations, and ensure high user satisfaction for photographers and resort managers.

### Key Targets:
1. **Zero-Downtime Reliability**: Eliminate all auth blockages, connection dropouts, and silent data sync failures. The system must work flawlessly offline and sync intelligently when online.
2. **Visual Modernization**: Upgrade the layout to feel premium, featuring:
   * **Typography**: Outfit for display headers, Inter for tabular data and controls.
   * **Color Palette**: Sophisticated HSL-tailored colors, deep dark modes, and subtle gradients (avoid generic pure colors).
   * **Micro-Animations**: Fluid transitions for route changes, state loading, and user actions (hover states, click ripples).
3. **Frictionless Onboarding**: Simplify the first-time setup for hotel desks. A wizard must guide the operator through printer, network, and database setups in under 2 minutes.
4. **Revenue & CRO Optimization**: Enhance print workflows, preview speeds, and AI face-matching tools to reduce client wait times and increase order volume.

---

## 2. Technical Architecture Blueprint (Architect Perspective)

From an architectural standpoint, the app must maintain a clean separation of concerns, high throughput on local SQLite databases, and strict security compliance.

### Core Architectural Mandates:
1. **Session & Cookie Lifecycle**:
   * Enforce double-submit CSRF checks and JWT token rotations.
   * Dynamically switch cookie `secure` flags based on `TLS_ENABLED` to prevent auth dropouts on local non-TLS deployments (`http://127.0.0.1:8090`).
2. **Database Performance & WAL**:
   * SQLite must operate in WAL (Write-Ahead Logging) mode with `PRAGMA synchronous = NORMAL` and daily WAL checkpoints to prevent write blocks.
   * Ensure explicit composite indexing on foreign keys (e.g., `photos(albumId)`, `orders(createdAt, status)`).
3. **Monolith Deconstruction**:
   * Refactor the 2,400+ line `CloudSyncService.ts` into a core orchestrator managing **16 isolated pipeline classes** (e.g., `LedgerPipeline`, `ResortBiPipeline`), each equipped with its own circuit breaker and dead-letter queue (DLQ).
4. **Memory Guardrails**:
   * Stream high-res images using `sharp` instead of buffer reading to prevent memory leaks during batch photo culling/imports.
   * Offload heavy AI face-indexing tasks to a dedicated CPU/GPU web worker.

## 3. Screen-by-Screen Audit & Improvement Plan (Full-Stack Developer)

### Phase A: Authentication & Onboarding Layer

#### 1. Login Page (`Login.tsx` & `authService.ts`)
*   **Audit**: Verify email validation constraints (Zod), CSRF token injection on pre-auth health checks, and rate-limiting triggers (5 attempts/min).
*   **CEO/UX**: Add smooth fade-in transitions. Display clear, user-friendly error messages (e.g., "Account locked for 5 minutes due to too many attempts") instead of blank pages.
*   **Full-Stack**: Save the authenticated user state to `localStorage` as a fallback only; verify that cookies are successfully persisted and sent in requests.

#### 2. Setup Wizard & Guide (`SetupWizard.tsx` & `SetupGuide.tsx`)
*   **Audit**: Check step validation (Hardware → Network → Database → Cloud).
*   **CEO/UX**: Build a step-by-step progress indicator with interactive card selections. Show real-time check marks when ports (like `8090`) are verified.
*   **Full-Stack**: Implement diagnostic checks inside the wizard to auto-detect the local IP address and test DB connection parameters before proceeding.

#### 3. Security PIN Challenge (`AdminPINChallenge.tsx`)
*   **Audit**: Ensure pin validation uses a constant-time comparison helper to prevent timing attacks.
*   **Full-Stack**: Save PIN attempts in the local session state and block entry for 1 minute after 3 failed attempts.

---

### Phase B: Core Application Shell & Analytics

#### 4. Layout & Sidebar Navigation (`MainLayout.tsx` & `Sidebar.tsx`)
*   **Audit**: Monitor memory leaks when switching between pages. Validate dynamic chunk loading recovery.
*   **CEO/UX**: Include a responsive folding sidebar. Display a global search bar with keyboard shortcuts (e.g., `/` to search) and active indicators for Cloud Sync and Thermal/CPU load.
*   **Full-Stack**: Centralize server-sent events (SSE) inside a React context to handle real-time notifications for assistance requests and hardware warnings.

#### 5. Dashboard Page (`Dashboard.tsx`)
*   **Audit**: Verify query caching times (React Query) for quick loading when returning to the dashboard.
*   **CEO/UX**: Convert layout into a bento-grid dashboard with animated statistics (e.g., revenue, daily sales, active kiosks).
*   **Full-Stack**: Fetch dashboard numbers asynchronously in chunks so the screen renders instantly, showing loading skeletons for pending widgets.

#### 6. Resort BI / Business Intelligence (`LocalResortDashboard.tsx`)
*   **Audit**: Confirm large date ranges do not block the SQLite main thread.
*   **CEO/UX**: Introduce visual charts (ApexCharts/Chart.js) showing photographer performance, package distribution, and hourly sales volume.
*   **Full-Stack**: Run query aggregation on pre-indexed columns and cache computed daily reports to reduce DB load.

---

### Phase C: Photography & Editing Workflow

#### 7. Albums Management (`Albums.tsx` & `Photos.tsx`)
*   **Audit**: Test importing 1,000+ images concurrently and check memory profiles.
*   **CEO/UX**: Add drag-and-drop file upload regions. Build high-fidelity thumbnail preview grids with instant lazy-loading as the user scrolls.
*   **Full-Stack**: Retrieve EXIF metadata (camera, photographer, timestamp) directly upon upload and queue them for background AI face-indexing.

#### 8. Canvas Photo Editor (`editor2/` & `PhotoEditModal.tsx`)
*   **Audit**: Check GPU hardware acceleration availability for TensorFlow.js face searches.
*   **CEO/UX**: Modernize the canvas overlay (Crop, Filters, AI Retouch). Support keyboard shortcuts for common actions (Ctrl+Z to undo, Arrow keys to navigate).
*   **Full-Stack**: Optimize canvas rendering using OffscreenCanvas to prevent UI freezing during complex filter adjustments.

---

### Phase D: Order Fulfillment & Kiosks

#### 9. Orders Board & List (`Orders.tsx` & `FulfillmentView.tsx`)
*   **Audit**: Verify vectors and locks on KanBan transitions (e.g., Pending → Processing → Ready).
*   **CEO/UX**: Build a drag-and-drop KanBan board. Highlight overdue orders in red and high-value orders with subtle animations.
*   **Full-Stack**: Integrate a local print queue manager that coordinates printer availability and outputs PDF layout slips directly via IPC.

#### 10. Products & Pricing (`ProductsPage.tsx` & `ProductsAndPricing.tsx`)
*   **Audit**: Validate input parameters (price positive numbers, name unique) using Zod.
*   **CEO/UX**: Create beautiful product cards that clearly show stock levels, active discounts, and linked printing formats.
*   **Full-Stack**: Integrate automatic stock reduction alerts when inventory drops below 10 units.

---

### Phase E: Settings, Security & Compliance

#### 11. Settings Tab Audit & Consolidation
*   **Audit**: Eliminate redundant settings pages, merge overlapping configurations, and purge unused components (like `CloudSync.tsx`) to improve UX and memory footprints in Electron.
*   **CEO/UX**: Streamline the settings sidebar from 20 to 16 tabs to reduce cognitive load on resort operators. Add intuitive sub-sections/internal tabs inside unified settings views.
*   **Full-Stack**:
    *   **Unified Database & Storage** (`DatabaseManagement.tsx`): Merge the old separate `DatabaseManagement.tsx` (WAL stats/integrity), `BackupSettings.tsx` (backup/restore zip imports), and `DataManagementSettings.tsx` (retention policy/manual scrub) into a single unified tab.
    *   **Unified Branding & Receipts** (`WatermarkSettings.tsx`): Merge `WatermarkSettings.tsx` (image watermarking/anti-theft) and `CustomerReceiptSettings.tsx` (invoicing detail/logo/tax options) into a single, cohesive view since they represent customer-facing assets.
    *   **Unified Session & Photo Classification** (`SessionTypesSettings.tsx`): Combine `SessionTypesSettings.tsx` (session names and prices) and `CategoryManagement.tsx` (album photo categories) into a single tab.
    *   **GDPR & Data Compliance** (`GDPRSettings.tsx`): Integrate the previously missing `GDPRSettings.tsx` (consent logs, breach registry, DPAs) directly into the settings layout to ensure full compliance.
    *   **Purge Unused Assets**: Delete `CloudSync.tsx` (redundant manual sync client) and clean up all lazy-load hooks and imports in `SettingsPage.tsx`.

## 4. Verification & Testing Framework

*   **Unit Tests**: Maintain 80%+ coverage using Vitest for all backend helpers and UI utilities.
*   **Integration Tests**: Run Playwright workflows to test the end-to-end checkout flow (Product Selection → Payment Sync → Print Trigger).
*   **Performance Monitoring**: Run periodic memory leak profiles using Chromium DevTools under Electron to ensure stable operation over a 12-hour shifts.
