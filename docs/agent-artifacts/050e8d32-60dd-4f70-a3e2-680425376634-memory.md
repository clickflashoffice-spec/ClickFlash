# ClickFlash Ecosystem Memory

This document stores persistent, high-level context that must be respected during all operations.

## Architectural Constraints
- **Master Server Port:** The Master App (Electron) serves the frontend and APIs locally on `http://localhost:8090`. Do not change this, as the Touch Kiosks hardcode or expect this port.
- **Tauri Transition:** We are pivoting long-term desktop development from Electron to Tauri. `moneytrash` is our Tauri testbed.
- **SQLite Ecosystem:** The system is heavily bound to SQLite (local encrypted databases via `better-sqlite3-multiple-ciphers`) and Cloudflare D1 (cloud). Complex relational writes must be batched to respect D1 limits.

## Project Structure
- `apps/master`: The photographer's central hub (Electron + React 19). Heavy image processing.
- `apps/touch`: The client-facing kiosk (Electron + React 19). Locked down, touch-first UI.
- `apps/gallery`: The client e-commerce site (Vite/React). Requires high conversion UI and R2 file delivery.
- `apps/management`: The business dashboard (Vite/React).
- `apps/moneytrash`: Financial analytics (Tauri + Next.js).
- `apps/website`: Public marketing site (Next.js 15).
- `packages/*`: Shared utilities, types, and UI components.

## Hard Rules
- **No Deletions:** Never delete any code files or apps without explicit, undeniable permission. Move to `_deprecated` folders if necessary.
- **Aesthetics Matter:** Do not ship basic or generic UIs. Use rich colors, smooth gradients, and micro-animations.
- **Security First:** Rate limits, Zod payload validation, and telemetry are mandatory for all backend services.
