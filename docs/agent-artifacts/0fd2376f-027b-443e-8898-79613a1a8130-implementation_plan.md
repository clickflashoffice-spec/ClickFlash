# 360-Degree Web Root & Packaging Architecture Audit & Permanent Fix Plan

This plan permanently fixes the `"Web root not found"` error encountered when launching `ClickFlash Master OS.exe`, and performs a 360-degree audit and hardening of both `Master` and `Touch` static asset serving and ASAR packaging.

## Root Cause Analysis
When `ClickFlash Master OS.exe` runs:
1. `electron-main.ts` forks `backend/server.js` using `ELECTRON_RUN_AS_NODE=1`.
2. Standard Node.js (`ELECTRON_RUN_AS_NODE=1`) does **not** have Electron's virtual `asar` filesystem patch enabled.
3. Because `apps/master/electron-builder.yml` previously only specified `asarUnpack: - "dist/backend/**/*"`, the frontend web files (`dist/master/index.html`) remained packed inside `app.asar`.
4. When `server.js` attempted to resolve `WEB_ROOT` via `fs.existsSync()`, standard Node could not read inside `app.asar`, causing all `WEB_ROOT` candidate checks to fail and resulting in `res.status(404).send("Web root not found")`.

## Proposed Changes

### 1. `apps/master/electron-builder.yml`
- Update `asarUnpack` to include `"dist/**/*"` so both `dist/backend` and `dist/master` (`index.html`, CSS, JS bundles) are unpacked to physical disk under `resources/app.asar.unpacked/dist/`.

### 2. `apps/master/electron-main.ts`
- Pass explicit `WEB_ROOT: getUnpackedPath("master")` in `backendEnv` when forking `server.js` so the backend process receives the verified physical path immediately.

### 3. `apps/master/backend/config/constants.ts`
- Enhance `resolveWebRoot()` to systematically check:
  1. `process.env.WEB_ROOT` (explicit override passed from Electron main process)
  2. `path.join(__dirname, '../master')` (standard unpacked `dist/master` alongside `dist/backend`)
  3. `path.join(process.resourcesPath || '', 'app.asar.unpacked/dist/master')` (explicit Electron unpacked path)
  4. `path.join(__dirname, '../../dist/master')`
  5. `path.join(process.cwd(), 'dist/master')`

### 4. `apps/touch/main.ts` & `apps/touch/electron-builder.json`
- Ensure `apps/touch/main.ts` static web root resolution checks all candidates (`path.join(__dirname, "../touch")`, `path.join(__dirname, "../renderer")`, etc.) so `Touch Kiosk` is equally hardened.

## Verification Plan
1. Recompile and package `apps/master` (`ClickFlash Master OS.exe`).
2. Verify physical presence of `resources/app.asar.unpacked/dist/master/index.html` in `release/win-unpacked`.
3. Launch `ClickFlash Master OS.exe` and verify HTTP 200 on `http://localhost:8090/` with the rendered React application instead of `Web root not found`.
