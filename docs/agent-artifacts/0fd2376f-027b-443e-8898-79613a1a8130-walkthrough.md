# ClickFlash Master OS — Startup Fix Walkthrough

## Problem
The ClickFlash Master OS Electron app crashed on startup with `ERR_DLOPEN_FAILED` due to native binary ABI mismatches, and previously with `Web root not found` errors.

## Root Cause Analysis

| Issue | Root Cause | Fix |
|-------|-----------|-----|
| `Web root not found` | `resolveWebRoot()` didn't check ASAR-unpacked paths | Added multi-candidate fallback in `constants.ts` |
| `ERR_DLOPEN_FAILED` | `better-sqlite3` compiled for Node.js ABI 137, but Electron 39 needs ABI 140 | Rebuilt binary + added ABI verification to build pipeline |
| SQL migration crash | Duplicate index name in migration 063 | Fixed index target |
| Missing JWT_SECRET | `constants.ts` threw on missing secret | Auto-generates on first run |
| **Recurring on every build** | `npmRebuild: false` + `ensure-native-deps.js` copied Node.js binaries without ABI check | **Added `verifyAndRebuildNative()` to afterPack** |

## Changes Made

### 1. [ensure-native-deps.js](file:///C:/Users/alamo/Desktop/ClickFlash/apps/master/scripts/ensure-native-deps.js) — **Permanent ABI Fix**
- Added `verifyAndRebuildNative()` function that runs during every build
- Checks if `.node` binaries in `app.asar.unpacked` match the target Electron ABI
- Auto-rebuilds via `@electron/rebuild` if mismatch detected
- Falls back to `prebuild-install` if rebuild fails
- Writes `.abi-verified` sentinel file for audit trail
- Includes Electron→ABI mapping table (v33–v40)

### 2. [electron-builder.yml](file:///C:/Users/alamo/Desktop/ClickFlash/apps/master/electron-builder.yml)
- `asarUnpack` now includes `dist/**/*` and all native module packages

### 3. [constants.ts](file:///C:/Users/alamo/Desktop/ClickFlash/apps/master/backend/config/constants.ts)
- `resolveWebRoot()` checks multiple candidate paths including ASAR-unpacked
- `JWT_SECRET` auto-generates securely on first run

### 4. [063_performance_indexes_v4.sql](file:///C:/Users/alamo/Desktop/ClickFlash/apps/master/backend/database/migrations/063_performance_indexes_v4.sql)
- Fixed duplicate index target
