# Fotiqo — Master Project Goal & Ecosystem Vision

**Last Updated:** July 2026 | **Status:** Active Development

---

## 🌍 Brand & Vision

**Fotiqo** is a next-generation, AI-driven photography ecosystem engineered to operate at global enterprise scale (100+ Master Locations worldwide). It bridges on-site photographers, automated intelligence systems, resort management, and end customers into a single, seamless platform — from shutter click to payment, anywhere in the world.

---

## 🏗️ Ecosystem Architecture (6 Apps + Cloud)

| App | Platform | Purpose |
|-----|----------|---------|
| **Master Kiosk** (`apps/master`) | Electron + React 19 (Port 8090) | On-site DSLR tethering, photo sync hub, local WebSocket server |
| **Touch Kiosk** (`apps/touch`) | Electron + React 19 (Port 8091) | Customer-facing self-service terminal |
| **Mobile Staff App** (`apps/mobile-staff`) | React Native / Expo (Android-only) | Photographer field operations: booking, check-in/out, payments, AI coaching |
| **Management App** (`apps/management`) | React + Vite (Cloudflare Pages) | Enterprise HQ dashboard: global fleet control, AI intelligence, finance |
| **Customer Gallery** (`apps/gallery`) | React + Stripe (Cloudflare Pages) | Web gallery accessed via QR scan: view photos, pay online or cash |
| **Money Trash** (`apps/moneytrash`) | Next.js 16 + Tauri | Internal accounting / financial reconciliation tool |
| **Cloud Backend** (`apps/cloud-backend`) | Cloudflare Worker (D1 + R2 + Stripe) | Global API: orders, auth, AI processing, webhooks |
| **Website** (`apps/website`) | Next.js 15 + Tailwind 4 | Public marketing site & onboarding |

## 🎯 Core Business Goals

### 1. Global Scale — 100+ Master Locations
- The Management App must support **100+ Master Locations** worldwide, organized by region (MENA, Europe, Americas, Asia-Pacific).
- A `Global Location Context Switcher` allows the admin to instantly toggle between Global Enterprise view or drill into a specific resort/hotel.
- All dashboards (revenue, fleet, AI) must aggregate or filter based on selected context.

### 2. AI-First Operations (Gemini API — No Ollama)
All AI is powered by **Google's Gemini API** via the cloud backend:
- **AI Manager:** Live fleet monitoring, automated photographer flagging, coaching dispatch.
- **AI Location Scout:** Google Maps heatmaps overlaying GPS check-in data, sales volume, and foot traffic predictions.
- **AI CEO:** Strategic revenue forecasting, dynamic pricing, staff allocation recommendations.
- **AI Coach:** Personalized in-app feedback on each photographer's mobile device.
- **AI Auto-Culling:** Kiosk-side blurry/blink detection before cloud upload.
- **AI Marketing:** Automated abandoned cart emails and upsell campaigns.

### 3. Mobile Staff App — Full Field Operations (Android)
- **GPS-Fenced Check-in / Check-out:** Correlated with location and sales for the heatmap.
- **Booking & Calendar:** Assigned gigs, customer info, time slots.
- **Session QR Generation:** One-tap QR that opens the Customer Gallery on the client's phone.
- **Cash Payment Confirmation:** Real-time WebSocket ping when a customer selects "Pay Cash." Photographer taps Confirm → photos are unlocked.
- **Stripe POS / Tap-to-Pay:** Stripe Terminal React Native SDK for in-person card payments.
- **Digital Waivers:** Customer signs legal consent directly on the photographer's phone.
- **Performance Dashboard:** Personal conversion rate, AOV, earnings vs. targets, AI coaching tips.
- **Photographer Earnings Ledger:** Daily cash vs. card breakdown, running totals.

### 4. Customer Gallery — Frictionless Scan & Pay
- Accessed by scanning the photographer's QR code on their own mobile browser.
- **Real-Time Photo Sync:** Photos appear instantly via WebSocket as they are taken.
- **Flexible Payment:** Stripe online checkout OR "Pay Cash to Photographer" flow.
- **Cash Flow State Machine:** `pending` → `awaiting_cash` → `photographer_confirms` → `paid` → photos unlocked.
- **Multi-Language Support:** Auto-translate for international tourists.
- **Upsell Engine:** Print packages, albums, friend-sharing discounts.

### 5. Management App — Global Enterprise HQ
- **Navigation:** 5 tabs — Dashboard, AI Intelligence, Operations, Finance, Settings.
- **Global Location Context Switcher:** Searchable dropdown supporting 100+ locations grouped by region.
- **Executive Dashboard:** Aggregated KPIs across all locations or filtered by selected site.
- **AI Intelligence Hub (3 workspaces):**
  - *AI Manager Workspace:* Live fleet map, photographer status badges, auto-flagging alerts, coaching hub.
  - *AI Location Scout:* Google Maps heatmaps showing profit zones, foot traffic clusters, and fleet coverage. AI recommendations panel with one-click fleet redeployment.
  - *AI CEO Workspace:* Revenue forecasting charts, dynamic pricing controls, staff allocation optimizer.
- **Operations:** Station fleet monitor, orders & sales, volume exports, assets inventory, sync logs.
- **Finance:** Revenue & income, expenses & payroll, capital & treasury.
- **Settings:** Staff management, license generator, session types, email campaigns, billing.
- **Photographer Management:** Virtualized list (100+ photographers), Performance Metrics modal (Conversion, AOV, AI insights), Digital Ledger modal (cash/card breakdown).

### 6. Master Kiosk — Lightweight & Reliable
- Targets modest hardware: **4-core CPU, 16GB RAM**.
- DSLR tethering via USB, image compression pipeline before cloud upload.
- Local WebSocket hub (`SyncManager`) broadcasting events to all connected clients.
- `broadcastCashPending`: Routes cash confirmation requests from Gallery to Mobile Staff app.
- Background processing queues to prevent memory spikes during high-volume shoots.

## 🛠️ Technology Decisions

| Concern | Decision | Reason |
|---------|----------|--------|
| AI Engine | Google Gemini API | No local LLM overhead; cloud-scale |
| Maps | Google Maps API | Heatmap support, global coverage, Places API |
| Payments | Stripe (Checkout + Terminal) | Online & in-person POS unified |
| Mobile | React Native / Expo (Android only) | Client requirement |
| Cloud | Cloudflare Workers + D1 + R2 | Edge-first, global low latency |
| Real-time | WebSockets (custom SyncManager) | Low-latency photo/event sync |
| State | React Query (server) + useState/useReducer (client) | Per project guidelines |
| Styling | Tailwind CSS (Management), Vanilla CSS (Gallery) | Per app conventions |

---

## 🔑 Key Design Principles

1. **Lightweight-first:** Every feature must work on a 4-core, 16GB PC. Heavy AI runs in the cloud.
2. **Offline-resilient:** Core operations (photo capture, local sync) must work without internet.
3. **AI-augmented, not AI-dependent:** AI features enhance, never block, core operations.
4. **Global by default:** All data models support multi-location, multi-currency, multi-language from day one.
5. **Security-first:** All customer data, payments, and photos require auth. Stripe handles PCI scope.
