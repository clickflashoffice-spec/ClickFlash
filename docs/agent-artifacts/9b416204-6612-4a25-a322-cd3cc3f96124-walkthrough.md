# Mobile App UI/UX & Layout Overhaul

I have completed the complete layout redesign and implementation for the ClickFlash `apps/mobile` client. The overhaul transitions the app from generic wireframes into a Tactical Industrial Utilitarian interface, specifically optimized for high contrast, outdoor glare readability, and fast-paced thumb ergonomics (Fitts' Law compliant >48dp targets).

## 1. Global Theming & Navigation Update
- **Tactical Theme Injected**: Modified `theme.ts` to strictly enforce the brand tokens (Background: `#070a12`, Elements: `#0f172a`, Tint/Accents: `#06b6d4`, Action/Success: `#10b981`).
- **Tab Restructuring**: Overhauled `app-tabs.tsx` to shift from generic `[Home, Explore]` routes to the custom ClickFlash ops modes: **Studio, Schedule, POS, Approvals**.

### Key UI Capabilities:
*   **Studio Dashboard (`index.tsx`)**: Rebuilt the hero section to feature a massive PTP session photo counter with a USB tether status indicator. The primary "GENERATE GUEST QR" action has been mapped to a 64dp sticky bottom action for flawless one-handed reachability.
*   **Schedule & Dispatch (`schedule.tsx`)**: Replaced standard list views with custom booking cards showing arrival times, VIP room details, and package types. We introduced a "GPS Range Widget" that visualizes spatial proximity to shooting locations (e.g., Sunset Pier) before allowing staff check-ins.
*   **Multi-Currency POS (`pos.tsx`)**: Reworked the checkout layout entirely. It now includes a horizontal scroll of currency selectors (`USD`, `EUR`, `AED`, `SAR`), rapid 1-tap package builders (e.g., Digital Single $25, Print Package $65), and a custom Fitts' law-optimized 3x4 numeric pad built from scratch rather than relying on the native keyboard.
*   **Approvals & Moderation (`approvals.tsx`)**: Split into two distinct card types (Cash and Photo Moderation) with dual badge counters pinned to the top. Implemented high-contrast `Warning/Amber` indicators for cash workflows vs `Tint/Cyan` indicators for photo approval batches. 

> [!TIP]
> **Fitts' Law Ergonomics**
> Throughout all 4 screens, every interactive element (currency selectors, keypad numbers, reject/confirm rows) was strictly set to a minimum height of `48px`, with primary actions spanning `64px` tall and anchoring to the bottom of the `SafeAreaView`.
