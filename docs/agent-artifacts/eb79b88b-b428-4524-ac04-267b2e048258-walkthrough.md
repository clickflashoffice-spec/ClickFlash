# ClickFlash Hardware & Cloud Architecture

We have fully connected the edge hardware capturing devices (Mobile Apps & Ride Nodes) to the central Cloudflare ingestion pipeline, and enriched the pipeline with Gemini AI Auto-Tagging!

## 1. Cloud Backend Ingestion (Cloudflare)

We created a highly-scalable, edge-first ingestion pipeline in `apps/cloud-backend` using Cloudflare Workers.

**Features Implemented:**
- **Zero-Egress Data Layer**: The API (`POST /api/ingest`) is built on **Hono**. It receives raw photo payloads and streams them directly into **Cloudflare R2** object storage, completely avoiding AWS S3 egress fees.
- **Relational Metadata Tracker**: Each photo's metadata (Room Number, Event Tag, Access Code) is saved into **Cloudflare D1** (Serverless SQLite), allowing the web dashboards to instantly query what photos belong to which event.
- **Background AI Tagging Engine**: The moment a photo is saved, the Worker sends an event to a **Cloudflare Queue**. A background worker picks this up to execute AI processing without slowing down the initial photographer upload.

## 2. Gemini AI Auto-Tagging (Google Gen AI)

To allow guests to easily find their photos without QR codes, we hooked up the Cloudflare Queue to **Google Gemini 1.5 Flash**.

**How It Works:**
- The background Cloudflare Queue consumer pulls the uploaded high-res image buffer directly from R2.
- It sends the buffer to the `gemini-tagger.ts` service, asking it to identify clothing colors, accessories, and the visual context (e.g., "waterslide").
- Gemini processes the image in less than a second and returns a strict JSON payload: `{"clothing_colors": ["red", "blue"], "accessories": ["sunglasses"], "context": "pool", "people_count": 2}`.
- This JSON payload is instantly saved to the `ai_tags` column in the D1 database, making the photo entirely searchable for the final Gallery web app.

## 3. Automatic Attractions (Sensorless AI Vision Trigger)

For fast-moving attractions (waterslides/rollercoasters), we built a **Dual-Camera Vision Rig** (`apps/ride-node`).

**How It Works:**
- The node connects to the expensive Nikon D7000 and a cheap $20 USB Webcam.
- An AI Vision Daemon uses OpenCV to analyze the webcam feed. 
- The exact millisecond the OpenCV script detects a human-sized object, it triggers the Nikon D7000 via `gphoto2` in a background thread.
- The high-res shot is instantly downloaded and uploaded to the new Cloud Backend.

## 4. Roaming Photographers (Android USB OTG)

Photographers standardize on Android devices connected directly to their Nikon D7000 via a USB OTG cable.

**Features Implemented:**
- **USB PTP Interface**: Pulls JPEGs directly over the USB cable the moment the shutter is clicked.
- **Room Tagging**: The ingestion UI (`apps/mobile-staff/app/(tabs)/ingestion.tsx`) forces photographers to enter the Room Number or Event Name before tethering.
- **SQLite Auto-Sync Queue**: Safely queues photos on the phone and trickle-uploads them to the Cloud Backend.

## 5. Guest Gallery Edge Migration (`apps/gallery`)

We have repointed the guest gallery React application (`apps/gallery`) to communicate directly with the new edge Cloudflare Worker API (`apps/cloud-backend`).

**Features Implemented:**
- **Edge Authentication & Photo Fetching**: Updated `cloudApiService.ts` to hit `POST /api/gallery-auth/login` and `GET /api/photos` on the Cloudflare Hono backend.
- **AI-Powered Natural Language Search**: The search bar in `CustomerGallery.tsx` reads directly from the `aiTags` returned from D1. Guests can enter natural queries such as "red", "sunglasses", or "pool" to instantly filter through hundreds of event photos.
- **Zero Paid SaaS Architecture**: The entire flow—from the photographer/ride upload to background Gemini tagging down to guest viewing and filtering—runs entirely across Cloudflare Workers, R2, and D1.
